# DataInsight_RAG 

An intelligent multi-modal question-answering system that seamlessly combines document retrieval, database analysis, and data visualization.

## Features

- 🔍 **Smart Routing** - Automatically determines optimal data source (RAG, SQL, or hybrid)
- 📄 **Document Analysis** - Retrieves answers from PDFs, reports, and research documents
- 🗄️ **Database Queries** - Generates and executes SQL for structured data analysis
- 📊 **Auto Visualization** - Creates charts from comparative data queries
- 💬 **Conversation Memory** - Maintains context across multiple questions
- 🔗 **Source Citations** - Provides citations for document-based answers
- 🤖 **LLM-Powered** - Uses Qwen3 via Ollama for intelligent processing

## Use Cases

- Research assistance across documents and databases
- Business intelligence queries
- Data analysis with automatic visualization
- Multi-source question answering
